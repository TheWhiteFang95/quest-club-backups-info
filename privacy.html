Privacy policy

How Quest Club Backups handles data

Last updated: 9 November 2026

Quest Club Backups is a private, single-user integration operated by the owner of a Quest Club learning-game installation and a personal Google Drive account. It is not a public service and doesn't register or accept other users.

1. What information is processed?

The integration backs up a SQLite database used by Quest Club. Depending on the family's use of the game, that database may contain child profiles, learning progress, rewards, purchases and parental settings. It is treated as private family data.

2. How Google Drive data is accessed

The integration requests the https://www.googleapis.com/auth/drive.file permission. It uses that permission only to create, list, download and delete the backup files and folders created by this integration in the operator's Google Drive. It is not used to access unrelated Drive documents.

3. How information is protected and stored

The private Oracle-hosted server creates database snapshots using SQLite's backup function. Rclone crypt encrypts backup contents and filenames on the server before uploading them to the operator's Google Drive. Google Drive contains encrypted backup files, not an unencrypted copy of the Quest Club database.

Google OAuth credentials and encryption configuration are kept on the operator's server, not embedded in this website or published in the source repository. The operator must separately safeguard recovery passwords and credentials.

4. Sharing and use

Backups are used only for continuity and recovery of the private learning game. The operator does not sell the data or provide the backups to other people. Google processes uploaded files as the storage provider under the account owner's Google Drive settings and Google's own policies.

5. Retention and deletion

The current backup configuration aims to keep the seven newest local and cloud database snapshots, deleting older matching cloud snapshots only after a newly uploaded backup has been verified. The operator can remove any remaining backups directly from Google Drive. Removing Google authorisation prevents further access through this integration; deleting backups is a separate action.

6. This public information website

These pages don't offer accounts, forms, cookies, advertising or embedded analytics. They do not receive or display child data, Google OAuth tokens or backup files. The hosting platform may keep standard request logs under its own privacy practices.

7. Contact

Privacy or access questions about this private integration can be directed to the operator using the user-support email shown on the Google OAuth consent screen for Quest Club Backups. This integration is operated solely for that account holder's personal use.

8. Changes to this policy

This policy will be updated if the backup integration's permissions, storage or data-handling practices materially change.
