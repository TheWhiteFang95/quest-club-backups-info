✦Quest Club Backups

Personal backup utility

Private, encrypted backups for Quest Club

Quest Club Backups is a private, single-user integration that preserves the saved data of a family learning game. It is not a publicly available app or a service offered to other users.

How it works

On a private server, the operator creates a consistent backup of Quest Club's SQLite database. The rclone tool encrypts the backup's content and filename before uploading it to the operator's own Google Drive.

The operator can retrieve and decrypt those backups if the game's server needs to be restored. This website contains no access to the game, database, backup files or authentication credentials.

Google Drive permissions

The integration uses Google's drive.file permission to create, read and manage the files it creates through the connected account. It is not intended to browse unrelated files in Google Drive.

The integration is controlled by the account owner and isn't available for other people to sign up for.

Privacy and data handling

Backups can contain child profile and learning-progress information, so they're encrypted locally before transfer. The website you're reading is informational only; it has no sign-in, analytics or tracking scripts.
